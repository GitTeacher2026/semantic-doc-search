تخزين MEGA (اختياري)

اختياري — اتصل فقط عند الرفع أو عرض ملفات MEGA. يمكنك استخدام البحث وباقي الأقسام دون اتصال.

الاتصال بـ MEGA اختياري. أدخِل البيانات فقط إذا أردت الرفع أو مزامنة الملفات، ثم اضغط «الاتصال بـ MEGA».

الصور تتطلب الاسم والمجلد. باقي الملفات يمكن تخصيصها اختيارياً. المجلدات المقفلة تتطلب كلمة المرور عند الإضافة أو التصفح.

البحث الذكي (فوري)

خيارات بحث متقدمة

تُطبَّق الخيارات فور تغييرها. «مطابقة حالة الأحرف» تؤثر على النص الإنجليزي.

بحث monographs — دساتير الأدوية

النتائج روابط Google Drive. يمكنك فتح الملف مباشرة أو سحبه (Leech) إلى خادم MEGA وإضافته للمكتبة.

الفهرس مأخوذ من Web of Pharma Pharmacopoeia Search Engine — النتائج روابط Google Drive مع خيار Leech إلى MEGA.

بحث SmPC — نشرة خصائص المنتج

اختر المصدر ثم ابحث بالمادة الفعّالة أو الاسم التجاري. يُعرض SmPC/النشرة الكاملة داخل نافذة منبثقة مع خيارات الترجمة والتنزيل.

مصدر النشرة
بحث مخصص — فلاتر متقدمة

الفلاتر تعمل بأفضل دقة مع DailyMed و drugs.com عبر OpenFDA NDC. لـ eMC تُستخدم ككلمات بحث إضافية. حقل ATC يقبل رمزاً (مثل C10AA05) أو فئة دوائية FDA (EPC/MoA).

بحث شهادات ISO / اعتماد الشركات

بديل عملي لـ IAF CertSearch المحدود مجاناً: ابحث مباشرة عبر أشهر هيئات التصديق (SGS، TÜV Rheinland/Certipedia، Bureau Veritas، Intertek، BSI، TÜV SÜD، DNV، LRQA، DEKRA، UKAS). النتائج الحية تُعرض داخل الموقع مع إمكانية عرض الشهادة وتنزيل PDF أو بطاقة الشهادة. بعض الهيئات تفرض CAPTCHA على البحث العام فيبقى رابط الدليل الرسمي كاحتياط.
